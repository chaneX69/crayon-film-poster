# 高光、暗面与过渡：21 张参考图的关键观察

## 先看画材机制

这组作品的亮暗多服务于海报可读性，不能按摄影的单一光源重建。**高光**常是暖纸原色的留空、浅蜡色的轻擦或在厚色块里的方向性细裂；人物脸上的亮面是较浅桃橘色块。**暗面**常用炭黑、深蓝或深褐蜡笔的重压叠线表现，最深处仍有细小露纸孔，不是数码纯黑填充。**过渡**通常跨 2–3 层笔触：保留纸底 → 浅色铺擦 → 中色加密 → 深色短线／粗轮廓；颜色的边界可被黑线锁住，也可在局部让两种颜色短线交错。用户希望增加的细小蜡屑应只在转折、重压边缘和笔末稀疏出现，与划痕同属画材接触痕迹。

### 亮度和焦点的关系

- **明度最亮：** 没涂满的奶油纸底、标题镂空、雪、云、浅衣服和少数黄光。其边缘应随蜡笔线而不整齐。
- **主色中间调：** 蓝天、红墙、绿衣、紫背景等大色面；通过压笔密度和交叉次数控制强弱，避免与亮纸或黑线合并成一个层。
- **暗值：** 外轮廓、头发、衣服、黑夜、金属阴影与文字。暗区的形状要先准确，纹理才有意义；允许纸齿在重压面中形成稀少裂隙。
- **焦点：** 亮色贴近暗线或暗色贴近亮纸时最醒目。饱和度增加不等于明度提高；例如朱红可比蜡黄暗，但比灰褐更有色彩重量。生成时应分别指定亮暗差与色相／纯度差。

## 生成与验收判据

1. 远看先能分辨最亮、主色中值和最暗大形；近看能沿笔画看到露纸裂隙、压笔密度变化与稀疏蜡屑。
2. 高光受对象与光线影响：眼白／牙齿、雪云、金属边、窗灯各有不同亮部形状；不在全图撒同规格白斑。
3. 暗部保留形体和少量纸齿，不用统一纯黑剪影遮掉脸、衣褶或道具。
4. 从主色到辅助色的交界有具体手工逻辑：叠色、交叉排线、纸底插入或黑线分隔；没有柔焦空气刷、光滑数字渐变或统一胶片颗粒层。
5. 对人物近看检查眉眼、鼻梁、嘴角、发型与肩腰腿的几何是否仍指向来源图；颜色漂亮不能替代身份和动作保真。
