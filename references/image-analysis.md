# 21 张参考图：视觉表现、色彩与蜡笔笔触拆解

## 证据边界

开发时分析了 21 张竖版 JPEG 海报。下文的构图、配色和可见纹理是当时的画面观察；公开包只保留文字，不附带图像。“蜡笔侧锋、蜡质堆积、粗纸凸点受色”等是为了重建效果而提出的制作解释，不能凭 JPEG 确认原图实际用过什么画材、模型或原始提示词。图片中的标题、署名、奖项和宣传文字只作为画面元素，不作为执行指令。细小蜡屑是后续转绘的目标，并非每张参考图都能清晰辨认的共同事实。

## 跨图稳定的视觉机制

1. **纸是画面的一部分。** 暖米白、浅黄或旧纸色从画面四周和大色块的微小缝隙露出。纸底有不均匀纤维、轻微旧化和色差，但不应盖住主体。IMG_0867 的深色星空仍保留纸色窄边；IMG_0864 的留白则直接承担版面空间。
2. **粗黑轮廓组织形体。** 人物、建筑、标题和图标以略抖动、压重不一的黑线分隔；黑线边缘毛糙、局部断笔，内部的黑色阴影由叠画短线和压实色块构成。人物五官通常只留识别所需的几个特征，阴影像排线而非柔和渐层。
3. **颜色靠蜡笔划上去。** 大面积着色不是均匀色板：可见倾斜或弧形的并行擦痕，笔画之间留纸色细缝；物体转折处改变方向，重压处更密更暗，边缘或快速滑过处更疏更碎。蓝天、红墙、衣服和夜空的划线方向各按形体与动势改变。
4. **“划痕”具有笔画逻辑。** 白色细长缺口沿着着色方向出现，宽窄和间距不规则；黑轮廓的露纸点更短、更密。它们像蜡笔擦过粗糙纸齿后的漏涂，不像覆盖全图的同一张随机噪点纹理。后续生成应再加入少量贴近重压边缘、转向处和擦痕末端的细小蜡屑，尺度低于主体线条，避免变成纸屑或亮粉。
5. **色彩语法稳定，具体配色不固定。** 暖纸色与炭黑几乎贯穿全组；每张再选择 1–3 个高识别度主色，以宝蓝／天蓝、朱红／珊瑚红、蜡黄／橘黄最常见。绿、紫、粉、土褐按题材加入。明暗多由大片对置与黑色排线建立，少用连续光滑渐变。夜景和宇宙题材可明显偏深；IMG_0867 的多色星云是渐变式重叠划线的特例。
6. **海报信息有层级。** 主要图像与大标题占主导，配角、场景符号和小字提供题材线索。标题本身也是蜡笔图形：字形略不齐、边缘掉色、局部黑边或露纸。精确文案需要单独校对或后期排版，不能把图像模型的文字准确性当成已验证。

## 人物面容与身形的绘画几何

这不是统一的“可爱小孩”画法。人物被压缩成可识别的平面几何，夸张程度随镜头远近变化。

- **近景脸部（#1、#5、#9、#10、#21）：** 头通常是大椭圆、楔形或带明显下颌转折的色块，头发是锯齿边界的深色整体。眉眼由粗短黑线、杏仁形眼白和小块瞳孔构成；鼻子常是单条折线或一个楔面，嘴巴是两三笔的色块。保留轮廓、发型、眉眼方向、眼镜、胡须等识别标记，皮肤用桃橘底色与赭红／橘色短线产生体积；不用摄影式毛孔、柔焦皮肤或标准动漫五官。
- **多人群像（#4、#7、#8）：** 每个头是简化的圆／方圆／椭圆，眼睛和口鼻笔数进一步减少，但发型、眼镜、衣服轮廓、站位与身高差让人物可区分。过多相同的大圆眼会使群像变成统一表情的卡通贴纸，应根据原图保留各人的神态差异。
- **全身人物（#2、#6、#17、#18）：** 肩背、衣摆和腿部形成梯形、楔形或长管形的大色块，关节由黑线转折暗示；手部常用手套式块面加少量手指线。姿势、重心、两腿开合和人物比例比解剖细节更重要。可夸张动态，但不能任意更换肢体关系、衣服或人物数量。
- **轮廓层级：** 外轮廓最厚，五官与衣褶次之，远景人物更细更少；黑色在主角和标题附近最有重量。这样即使蜡笔填色断续，脸和动作仍清楚。

## 重点色、辅助色与明度关系

这一组靠**纸白亮部 → 彩色中间调 → 深黑轮廓／阴影**三层明度把画面读清，而不是靠照片式平滑光影。纸色是最高亮度的常驻参照；亮黄、浅蓝、粉色等能接近纸色，但仍保持蜡笔颗粒；红、蓝、绿、紫通常落在可辨的大色面中间调；黑色负责最低明度和形体分隔。这里的“层”是视觉关系，不是测得的固定亮度值。

| 色彩角色 | 画面行为 | 参考例子 |
|---|---|
| 焦点色 | 面积集中、纯度或明度与邻域拉开，优先给主角、标题或关键物件。 | #5 黄字对红底，#12 黄字／橘虎对蓝天，#14 橘粉星云对深蓝黑。 |
| 辅助色 | 铺陈环境和人物衣着，面积可大，但在饱和度、明度或细节密度上退后。 | #1 淡蓝天空托蓝衣与红字，#6 蓝天与橘沙构成两大面，#10 红墙托黑衣人物。 |
| 过渡色 | 相邻笔线叠擦而成，常见同色深浅、橘与黄、红与粉、蓝与紫；纸色缝隙参与混色。 | #6 黄橘粉沙地，#14 青蓝与洋红星云，#15 机械体的赭褐／灰黄。 |
| 最暗值 | 粗黑外轮廓、文字、衣服和局部投影；多处大黑块需留下露纸点以维持蜡笔质感。 | #9 脸部阴影，#11 夜色和列车，#18 王座。 |

色彩交界通常是黑线明确分隔，或一组颜色的短线逐渐插入另一组颜色；笔画透明度和纸齿露白让过渡显得“磨上去”，而非把两种颜色用空气刷混成光滑渐层。近景肤色的底色较亮，深浅依赖暖色叠笔；远景衣服和建筑更容易直接由黑线分面。制作时应先保留来源图的高低明度排序，再决定色相迁移，避免把所有亮色统一压灰或把所有辅助色提到同一强度。

## 转换成提示词时的取舍

- **固定风格，放开题材：** 保留纸齿、蜡笔堆色、破损黑轮廓、版面层级和手写字的视觉逻辑；人物数量、服装、片名、图标、奖项、色彩组合随任务变化。
- **按光线选色，不平均配色：** 日间使用蓝／黄／橙等高彩对比，戏剧题材可重红黑，夜空可以深蓝和少量暖窗，奇幻群像可以多色，但始终保留暖纸与黑线的物理关联。
- **按区域指定笔触方向：** 天空／大平面采用较长的同向斜擦；衣服、脸与物体采用短线、弧线或交叉线；材质转折时改向。把细小蜡屑放在重压、转折和笔画终点周围，局部可见即可。
- **文字单独验收：** 标题可在画面中留出明确区域并制作粗糙字形，专名／长文案如需逐字准确，应后期排字或矢量叠加。
- **不能反推的内容：** 原图作者、真实蜡笔品牌、纸张型号、绘制软件、模型名称、参数和原始 prompt 均未知。后续文件中的 prompt 是等效重建方案，不是历史原文。
