# 当次出图验收与版本记录

只为实际生成的图填写适用项；不把这份清单塞进绘图提示词。记录当次源图与成品版本，分开写观察、推断和未验证。每项用 `pass`、`fail`、`unverified`；真正不适用才用 `not-applicable` 并说明原因。用户明确允许改变的部分按本次目标判断，不按“原图不得改变”验收。

| 记录线 | 最小核对 |
| --- | --- |
| 技术 | 能否打开实际文件；方向、尺寸、格式、源图只读与成品另存是否成立。生成式转绘不承诺逐像素一致。 |
| 视觉 | 本次需保留的身份／空间／文字是否成立；人物几何、黑色勾边、蜡笔底色、纸齿划痕和细屑是否真在形体中出现；主辅色、亮暗面、高光及过渡是否清楚。 |
| 严格参考或数值 | 只有当次要求精确颜色、纹理比例、逐字排版或其他量化目标时启用；写明来源版本、区域、尺度、测量方法和限制。未测量写未知，不把提示词里的 HEX 当成成品命中。 |
| 用户反馈 | 明确认可、只认可局部／相对偏好、明确否定或尚未评价分别记录；认可某版不替代技术或视觉复查，也不授权入库、公开或训练。 |

适屏缩小看全图的人物手绘感和海报层级；原尺寸看手脸、眼镜、帽檐、遮挡、线条断续、蜡笔色块内部、划痕、蜡屑和文字。近景手、牙齿、皮肤、帽衣若因指节皱褶、逐颗牙齿和密集微线而显得过于精细，即使蜡笔底色成立，也单列人物几何 `fail`；定向减少细节后还要确认大色块涂色完整。玻璃或镜面存在时，区分反射、透射与实物；镜中人不当新增人物。云、皮肤、布、玻璃、金属各自检查亮形，不套统一白色高光。砖缝、百叶和栅栏属于物体结构时，不误判成机械填色排线。

任一核心项 `fail` 不靠其他项平均抵消。基底像照片加纹理、人物身份错、必要的蜡笔底色缺失时，按清楚的错误从源图作一次定点重绘；修正后复查受影响的形体、颜色、明度与已认可局部。若仍失败，报告失败并停下，不连续抽图。每次生成及当前选用版分别记，较新版本不自动取代用户认可版。
