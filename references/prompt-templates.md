# 两种输入模式的可用提示词模板

先看目标图并填写方括号字段。先列本次**需保留／允许改变／不可编造**的内容，再把目标图作为第 1 张输入。按 [参考机制索引](atlas.md) 选择 1–3 种画法；只有当次实际提供且获准使用风格图时，才加入图片并逐张说明职责。以下保留项是可编辑字段，不是“原图不许改变”的一刀切规则。模板的色彩描述是关系，不能在未看目标时填固定 RGB。

## A. 用户照片 → 蜡笔电影海报

```text
第 1 张图片是当次人物与场景的事实来源。把照片设计为[来源比例或指定比例]暖纸蜡笔电影海报。本次须保留：[按用户目标填写人物身份锚点、姿势、物件或场景]；允许改变：[裁切、位置、简化、重排或其他已允许的改动]；不可编造：[真实品牌、奖项、未经授权的新物件等]。若要保持人物可辨，近景脸逐人锁定[头部朝向、帽檐、镜框与镜腿、鼻梁、下巴、发际、手/杯遮挡位置]。后续参考图仅分别提供[明确命名的蜡笔画法机制]，不把其中的电影人物、片名、品牌和场景带进目标。

构图：[主角在何处、远中近景、标题区、主体与负空间比例]。标题：[用户给出的文字；若未给则预留区域，不擅自写新字，不编造真实电影奖项与演职员表]。人物要从原照重新概括形体，不能保留摄影人物只加蜡笔纹理：脸部用参考图式椭圆/楔形色面、锯齿黑发、少笔粗眉杏仁眼、折线鼻和简化嘴；身体用梯形肩背、衣摆、长管形四肢和清楚的重心。若有建筑，先把亮墙、暗墙、窗洞和檐口概括为大色面，再用粗细变化的蜡笔笔画擦出颜色，仅以少量不规整结构线提示砖缝与细节，不能照搬照片式密集砖纹。

色彩：纸底是最高亮度的暖米色，[重点色及其焦点对象]有比邻域更明确的纯度或亮暗差；[辅助色]支撑环境与人物；[最暗形体]用炭黑/深蜡色定形。保留原图的高光与暗面位置和明度排序；高光由纸白留空或浅蜡色形成，暗面由宽侧锋深蜡色与少量局部短排线形成，色块保持干净。色彩过渡靠断续相邻笔画、轻微交叉擦画和露纸缝，不用光滑数字渐变。

用蜡笔侧锋在纸齿细微、纸面柔和的暖纸上铺色。除有意留出的纸白，天空、墙、地面、人物、道具和暗面的底色都由可见的蜡笔宽笔及叠笔形成；不能先铺平整的数码底色，再叠几道蜡笔线或纸纹。笔画沿物体体积改变方向。[点名画面中三处最大填色区]分别安排足以填满形体的宽侧锋、可见纸齿缝和不同的手腕运动；在[适合圈涂的局部]明确画出可见弧线、圈涂或回笔，其他地方保留断续直线。笔画覆盖不能稀疏到显得没涂完，也不能靠同角度的密集细斜线填满。线条有不周期的轻微抖动、长短和压力变化、提笔断线。用中等线重、压笔不匀的黑线清楚勾勒物体，外轮廓略重于内部细节，但不形成宽黑边框。只在部分色块保留顺着笔向的细长露纸划痕、微小漏涂和少量贴在重压边缘/笔末的蜡笔碎屑；纸底和浅色面保持干净。全画保持可读的主次及本次规定的人物关系；避免重复压花纸纹、灰脏蹭痕、滤镜式统一颗粒、塑料高光、动漫化五官、五彩纸屑和错误可读文字。
```

## B. 原电影海报 → 蜡笔画材转绘

```text
第 1 张是需要转绘的原电影海报，是人物、海报构图、道具、标题和版面位置的权威依据。将整张原海报重绘为暖纸蜡笔手绘海报：保留[主体人物数量/脸部可识别特征/姿势/相互关系]、[关键道具和场景]、[主标题与重要文案的位置、字级、方向]、[原图高光/暗面/主体重点色的明度排序]。后续图片只提供蜡笔笔触、纸张、人物几何和颜色叠擦的画法，不导入其中的具体电影内容。

人物脸部转为有个体差异的椭圆或楔形色块、清晰且线重适中的黑色轮廓、少笔眉眼鼻口；身形转为清楚的梯形肩背、楔形衣摆、长管形肢体，保持源海报的身份线索、姿势和人物数量。把原色彩归入[重点色]、[辅助色]、[纸底亮部]与[最深黑色]，维持它们在源海报中的视觉优先级；通过宽侧锋与疏朗断续短线形成较亮面、中间调和暗面。亮部用露纸及浅色蜡痕，暗部用深蜡色块并留下稀少纸齿裂隙；过渡是断续相邻短线，不是柔焦喷绘。

若原海报含摄影肖像或照片拼贴，明确要求从空白纸重新概括人物：近景脸用约 2–3 个可辨的蜡笔肤色色面，少笔杏仁眼、折线鼻、嘴与胡须，头发和衣服归为大块几何形体；保留人物朝向、发型、姿态及撕纸等叙事结构。缩小看必须像儿童手画的成人角色。禁止保留写实眼窝、皮肤细节、连续摄影阴影和照片式衣褶后仅叠加蜡笔排线或纸纹；版面准确但人物仍像照片，判为失败。

近景人物还需控制细节上限：保留识别表情和手势，但手掌只画大掌面与少量粗手指，不描写实指节皱褶；牙齿优先合成一条浅色块，只用几笔分隔；帽子和衣物用少量宽蜡色面，不以密集微细排线模拟写实材质。删细节后仍用宽侧锋涂足底色，不要变成稀疏未上色。

暖色纸张有柔和、细微的纤维和纸齿；除刻意露出的纸白，所有着色区域的底层也由可见蜡笔宽侧锋及叠笔构成，不能是平整数码色块。色块涂满形体但保留蜡笔摩擦露纸的细缝，细线刻画五官与道具，物体轮廓用略重于内部线条的黑蜡笔勾勒，不包宽黑框。线条有轻微手抖、提笔断线、局部回笔或圈涂，疏密不均但色块干净；不能稀疏到未涂完，也不能形成机械密排线。少量细长露纸划痕沿实际笔画方向，细小蜡笔碎屑只贴近少数边缘、转折和笔末。原海报文字尽量保持原文与位置；若某些长文案难以可靠生成，优先保留准确的文字区和层级，后续按源图校对排字。避免改变海报叙事、人物、标题结构，也避免灰脏蹭痕、压花浮雕纸纹、统一纸纹滤镜、光滑渐变和满图噪点。
```

## 提示词检查

- 目标图的主体事实是否写在风格描述之前？参考图的角色是否明确写为“仅风格”？
- 人物几何是否具体到脸形、眉眼鼻口、头发轮廓、身体块面和动作重心？
- 是否把重点色、辅助色、亮纸与最暗值分别命名，说明明度与饱和度的关系？
- 高光是什么物体上的什么形状？暗面靠哪组排线或块面？色彩在什么边界如何叠擦？
- 划痕、露纸和蜡屑是否依附于笔画，而非一张全图覆盖纹理？
- 纸底是否柔和干净，所有非纸白底色是否也由蜡笔涂成，物体轮廓是否仅勾边且线重适中？
- 着色覆盖是否充足，同时仍看得见纸齿、断线和手腕转笔？
- 三处最大色块是否各自有不同的笔画运动，适合的局部能否在成图中看见圈涂，而非仍被密集同角度斜线占据？
- 人物在缩小后的成图里是否一眼能看出手绘几何，而非照片轮廓加纹理？建筑是否有真实的粗蜡笔擦画，而非摄影砖纹上盖细排线？
- 近景的手、牙齿、帽子和衣服是否仍有写实小纹路或密集细线？即使蜡笔色层真实，只要适屏观看仍像精细专业肖像，就要先概括形体与细节层级。
- 若本次要求保持人物身份，把近景人脸同原照片并排看：侧脸朝向、帽檐、眼镜、鼻梁及下巴是否仍能辨认？身份锚点出错时，不因新稿其他质感较好就替换用户已认可的版本。
- 百叶窗、栏杆、砖缝等重复线条是否属于物体本身？先保留其可辨的结构节奏，再处理蜡笔线质，不因规则就自动删成大暗块。
- 需要逐字正确的文案是否列出了校对或后期排字步骤？
