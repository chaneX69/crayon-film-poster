# crayon-film-poster

把照片设计为蜡笔电影海报，或把已有电影海报按原有主体和版面重绘为蜡笔画。重点是从人物形体到大片底色都重新画出可见蜡笔笔触，而不是在照片上叠加纸纹。

## 使用

将本仓库放进支持 `SKILL.md` 的智能体技能目录，调用 `crayon-film-poster`，提供当次目标图片，并说明需要保留的主体、文字和版面。技能会先检查原图，再按 [SKILL.md](SKILL.md) 的两种模式制定画法、生成一版并验收。需要图像输出时，运行环境必须提供能接收图片的生成或编辑工具。

仓库包含 21 组海报的文字观察、[视觉机制索引](references/atlas.md)、[提示词模板](references/prompt-templates.md)、[等效重建案例](references/prompt-cases.md) 和 [验收记录格式](references/acceptance.md)。这些内容可在没有风格参考图时使用。

## 素材边界

仓库不含电影海报图片、用户照片或历史生成图。原开发时使用的 21 张参考图没有完成再分发许可核验，因此没有上传。若自行加入参考图，请确认其使用权限，并让目标图片始终负责人物、场景与文字事实；风格参考只负责画法。
